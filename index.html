Static Website Hosting on Amazon S3

A hands-on project demonstrating how a static HTML website can be stored and served using Amazon S3 website hosting.

Explore the project

Project Overview

The goal of this project is to publish a simple static website using an Amazon S3 bucket. The website files are maintained in GitHub for version control, then uploaded to S3 when AWS access is available.

01 · Website

A responsive website built with HTML and CSS. No server-side code is required.

02 · Storage

Amazon S3 stores the website files as objects inside a bucket.

03 · Hosting

S3 static website hosting can serve the index document through a website endpoint.

AWS Services & Tools

Amazon S3

Object storage used to store and serve static website files.

GitHub

Source control and project documentation repository.

HTML & CSS

Front-end technologies used to create the website.

Implementation Workflow

  1. Create an S3 bucket in the selected AWS Region.
  2. Upload index.html to the bucket.
  3. Enable Static website hosting and set the index document to index.html.
  4. Configure only the required public read access if public website access is intended.
  5. Open the S3 website endpoint and verify the page.
  6. Document the configuration and testing evidence in this GitHub repository.

Project status: Website source and documentation are prepared. AWS deployment and live endpoint verification must be completed from the owner's AWS account.
